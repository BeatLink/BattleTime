# QR code

Shows a QR code that the NeoTime companion app made, such as a link, a contact or a Wi-Fi network,
so another phone can scan it from the watch.

## Using it

- In the companion app, type the text or link, or fill in a Wi-Fi network's name and password, and
  add a caption if you like. The phone makes the code and sends it to the watch.
- Open the app and hold the watch up to the scanner. The code is black on white, the screen goes to
  full brightness and stays on while the app is open.
- The code is drawn as large as fits; codes too large to scan on the screen are refused by the
  companion app.
- Without a code the app says to make one in the companion app.
- A code sent while the app is open shows the next time it opens.
