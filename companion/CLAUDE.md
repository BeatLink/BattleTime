# NeoTime Companion App

Expo (React Native) companion app for the NeoTime watch firmware in the sibling `NeoTime` repo.
Read [README.md](README.md) for the layout and the protocol.

- Screens live in `src/app` (Expo Router). Bluetooth stays behind `src/ble/transport.ts`; screens
  use the `useWatch` hook and never import `react-native-ble-plx` directly.
- Message shapes in `src/protocol/gadgetbridge.ts` mirror `NeoTime/wasp/gadgetbridge.py`, and
  `src/protocol/packages.ts` mirrors `NeoTime/wasp/pkgmgr.py`. Change each pair together.
- `src/packages/bundled.ts` is generated by `npm run import-packages <dir>` from NeoTime's
  `tools/mkpkg.py` output. Do not edit it by hand.
- Verify with `npm test`, `npm run typecheck` and `npm run lint`. BLE needs a dev build; web and
  Expo Go use the mock transport, which answers package commands.
