## Default Permission

Lets the companion's window use every part of the phone bridge.

#### This default permission set includes the following:

- `allow-has-notification-access`
- `allow-open-notification-access-settings`
- `allow-request-call-permissions`
- `allow-is-do-not-disturb`
- `allow-answer-call`
- `allow-reject-call`
- `allow-silence-call`
- `allow-media-command`
- `allow-is-ignoring-battery-optimizations`
- `allow-request-ignore-battery-optimizations`
- `allow-associate-watch`
- `allow-locate`
- `allow-open-uri`
- `allow-start-activity`
- `allow-send-broadcast`
- `allow-register-listener`
- `allow-remove-listener`
